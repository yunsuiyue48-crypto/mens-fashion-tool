# 云岁月 · POLO 衫运营中枢

以 POLO 衫为单一主线的静态运营站点。解压后双击 `index.html` 即可离线浏览，也可直接推送到 GitHub Pages。

## 页面结构

| 文件 | 页面 | 内容 |
|---|---|---|
| index.html | 首页 | 数据总览、品相速览、20 条路径概览、合规文件入口 |
| category-guide.html | 类目指引 | 20 条云岁月对接路径（含大码 2 条），按场景分类筛选、一键复制 |
| appearance.html | 品相图鉴 | S / A 两级品相特征拆解（背景·领型·门襟·版型·动作·人种·调性）+ 88 张风貌图，点击放大 |
| style-ref.html | 品相分类 | 5 大风格（A 经典珠地 / B 高尔夫功能 / C 户外速干 / D 新奇印花 / E 网球条纹）各 10 款选款参考，含上架路径、面料卖点、中英主图话术 |
| top-goods.html | TOP 商品 | 10 月 POLO 衫 479 款，按区域（glo / eu / us）聚合，支持图片视图与表格视图 |
| visual.html | 视觉优化 | 两套品相拍摄规格 + 主图指令生成器（中英双语） |
| title.html | 标题优化 | POLO 专用词库（图案/面料/版型/领型/门襟/功能/场景/细节）+ 标题生成，含功效宣称资质提示 |
| recruit.html | 招品回品 | 11.9 回品参考图库（146 款 / 572 张，主图在前、轮播图在后，点击放大） |
| ideas.html | 爆款延改 | 图案胚衣延改方向（领型 / 肌理 / 条纹 / 面料 / 拼接 / 辅料） |

## 维护方式

- 新增路径：编辑 `category-guide.html` 中的 `.path-card` 块，`data-cat` 控制所属筛选分类，`data-free="1"` 表示免审。
- 新增词条：编辑 `title.html` 顶部的 `DIMS` 数组，格式为 `['English','中文']`；需要资质提示的词条写成 `['English','中文','需资质']`，卡片上会自动出现「需资质」标记。
- 功效词规范：`UPF 50+` 仅在具备检测报告 / 资质授权时使用；抗菌类词条属夸张描述，请勿添加。
- 新增拍摄维度：编辑 `visual.html` 顶部的 `GROUPS` 数组，格式为 `['中文名','English prompt','中文描述']`。
- 新增品相分类款式：在 `style-ref.html` 中复制一个 `<article class="card">` 块，`data-cat` 对应 A–E，图片放 `images/` 并在 `img src` 与 `.thumb` 的 `data-img` 同步替换（缺图时卡片自动显示占位，不会破图）。
- 更新回品：用新表按「行业 id / 商品主图URL / 商品轮播图URL」三列重新生成 `recruit.html` 的 `.recruit-card` 块即可。

## 部署到 GitHub Pages

1. 解压压缩包，把里面的所有文件（`index.html`、各页面 HTML、`style.css`、`README.md`、`.nojekyll`）直接放在仓库根目录（`.nojekyll` 为隐藏文件，请确认一并上传）。
   - 「品相分类」（`style-ref.html`）的 50 张款式图按 `images/A01.jpeg` … `images/E10.jpeg` 引用。若仓库根目录已有 `images/` 目录，直接复用即可，无需改动；若尚未上传图片，卡片会自动显示「图片待补」占位，不会出现破图，补齐图片后自动恢复。
2. 仓库 Settings → Pages → Build and deployment → Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。
3. 等待 1 分钟左右，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。
4. 若更新内容后页面没变化，强刷（Ctrl / Cmd + Shift + R）或清一次浏览器缓存。
