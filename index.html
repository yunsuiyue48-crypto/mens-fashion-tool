类目指引

先总览，再选择精准上新路径。

模块 02

开款方向

支持三大类款式参考。每张卡片可同时绑定 JPG/PNG 图片与 PDF 款式资料。

上传说明： assets/styles/ 后，将文件路径填入对应输入框。
模块 03

视觉优化

围绕人模、服装展示、动作姿势、场景、背景、光线、风格与构图生成中文电商图片 Prompt。

生成的视觉 Prompt
模块 04

标题优化

套装、正装、棉羽三大类目独立词卡。词库基础来自《分维度枚举词_中英对照.xlsx》，保留中文释义、英文标题词与搜索变体。

原始词库：下载《分维度枚举词_中英对照.xlsx》
所有卡片均支持多选。建议按“核心品类词 → 套装规格/版型 → 风格 → 面料/细节 → 季节 → 场景 → 颜色”的顺序组合。
生成的英文标题

招品 / 回品
